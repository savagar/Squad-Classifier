The King of Limbs | Squat Classifier

This project is a squat classifier developed for AML Lab and AML Devices subjects for cohort 2024-2025 at Imperial College London.

Team members:

  • Avalos Garcia, Salvador
  • Cui, Endong
  • Yang, Hongjoon

This project describes the design, implementation and evaluation of an IMU-based deep squat classification system designed to improve lower body performance during deep squatting and effectively reduce the risk of injury to trainers. The wearable device for this project consists of five IMU sensors, and a microcontroller unit (Arduino) equipped with a heart rate sensor, an OLED display, which together provide real-time feedback on squatting posture. The project followed a standardized data collection protocol, with a total of 1,080 squat samples (Simple, Narrow, and Plie) collected from 10 participants, which were then pre-processed (normalization, padding and interpolation) to ensure consistency of the data and to facilitate the training of the ensuing machine learning model.

Three machine learning models were assessed to classify squat movements: Support Vector Machine (SVM), Long Short-Term Memory (LSTM), and a Transformer Deep Learning model. The SVM model, optimized via Grid Search, achieved a best cross-validation accuracy of 67.5%, highlighting the challenges of non-linear time-series data. In contrast, the LSTM model attained 38.42% accuracy, while the Transformer model obtained 78.83%. Visualization methods such as PCA and confusion matrix revealed significant feature overlap in the data for this project, with the simple squat being particularly prone to misclassification due to similarity to narrow squat.

Although there were some hardware limitations: multiplexer wiring stability, OLED and heart rate sensor update frequency, the squat detection system designed in this project succeeded in demonstrating real-time monitoring and feedback capabilities of the squat. Proposed future work consists in expanding the dataset, migrating microcontroller to a model that can deploy TinyML framework, and improve sensor fusion to enhance performance in a wider range of fitness and rehabilitation environments.

Keywords: Applied Machine Learning, Machine Learning, Deep Learning; Inertial Measurement Unit; Squat classification; SVM; LSTM; Transformer
